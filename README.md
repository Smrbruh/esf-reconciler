# Инструмент сверки ЭСФ

**АО КазАгроФинанс** — автоматическая сверка электронных счетов-фактур между выгрузками из 1С и государственной ИС «ЭСФ».

## 1. Установка

### Требования

- **Python 3.9 или новее** — скачать с [python.org](https://www.python.org/downloads/)
- Windows 10/11, macOS, Linux

### Шаги установки

**1. Скачайте и распакуйте архив проекта** в любую удобную папку, например `C:\ESF_Sverka\`.

**2. Откройте командную строку** в этой папке.
   - В Windows: нажмите `Shift + правая кнопка мыши` в папке → «Открыть окно PowerShell здесь» (или «Открыть окно команд здесь»).

**3. Установите зависимости:**

```bash
pip install -r requirements.txt
```

Это установит все необходимые библиотеки. Нужен интернет, занимает 1–2 минуты.

**4. Структура папок после установки:**

```
ESF_Sverka/
├── esf_reconcile.py    ← основной скрипт
├── config.yaml         ← настройки
├── requirements.txt
├── README.md
├── input/              ← сюда кладите входные файлы
│   ├── 1c_export.xlsx
│   └── esf_export.xlsx
└── output/             ← сюда сохраняются отчёты
```

## 2. Настройка config.yaml

Откройте файл `config.yaml` в любом текстовом редакторе (Блокнот, Notepad++, VS Code).

### Пути к файлам

```yaml
file_1c:  "input/1c_export.xlsx"
file_esf: "input/esf_export.xlsx"
```

Укажите имена ваших файлов. Если файлы находятся в другом месте, можно указать полный путь:
```yaml
file_1c:  "C:/Users/Иван/Desktop/выгрузка_1с.xlsx"
```

### Ключевая колонка

```yaml
key_column:
  in_1c:  "Номер ЭСФ"
  in_esf: "Рег. номер"
```

Это самый важный параметр. Укажите точные названия колонок с номером ЭСФ в каждом файле.

> **Совет:** Откройте ваш Excel-файл, посмотрите название нужной колонки и скопируйте его сюда точь-в-точь (включая регистр букв и пробелы).

### Маппинг реквизитов

```yaml
fields:
  "Дата":
    col_1c:  "Дата документа"
    col_esf: "Дата выписки"
  "Сумма оборота":
    col_1c:  "Сумма без НДС"
    col_esf: "Оборот"
  ...
```

Для каждого реквизита укажите, как называется соответствующая колонка в файле 1С (`col_1c`) и в файле ИС ЭСФ (`col_esf`).

Если какой-то реквизит отсутствует в вашем файле — поставьте символ `#` перед строкой, чтобы закомментировать её:
```yaml
  # "Статус ЭСФ":
  #   col_1c:  "Статус"
  #   col_esf: "Состояние"
```

### Погрешность сумм

```yaml
amount_tolerance: 1.0
```

Разница между суммами до 1 тенге не считается расхождением. Можно изменить, например, `0.01` для копеечной точности или `5.0` для допуска в 5 тенге.

### Настройки CSV

```yaml
csv_encoding:  "utf-8-sig"
csv_delimiter: ";"
```

Используется только если входные файлы в формате `.csv`. Если файлы `.xlsx` — этот раздел игнорируется.

## 3. Запуск

**1. Положите входные файлы** в папку `input/` (или в папки, указанные в `config.yaml`).

**2. Запустите скрипт:**

```bash
python esf_reconcile.py
```

**3. Прогресс выполнения** отображается прямо в консоли:

```

════════════════════════════════════════════════════════════

🔍  Загружаю файл 1С...
✅  Файл 1С загружен: 1 245 записей  [input/1c_export.xlsx]
🔍  Загружаю файл ИС «ЭСФ»...
✅  Файл ИС ЭСФ загружен: 1 198 записей  [input/esf_export.xlsx]
🔍  Выполняется сверка...

ℹ️   Только в 1С:               47
ℹ️   Только в ИС ЭСФ:            0
ℹ️   Записи с дубликатами:        6

✅  Полностью совпадают:       1 117

💾  Отчёт сохранён: output/protocol_2026-06-11_14-32.xlsx
```

**4. Готовый отчёт** будет в папке `output/` с именем вида `protocol_2026-06-11_14-32.xlsx`.

## 4. Как читать отчёт

Отчёт содержит 6 листов (вкладок) в Excel.

### Лист «Сводка»

Общая статистика сверки: сколько записей в каждой категории. Смотрите здесь сначала, чтобы понять масштаб расхождений.

### Лист «Только в 1С» 🔴

Счета-фактуры, которые есть в 1С, но **не найдены** в ИС «ЭСФ».

Возможные причины:
- ЭСФ ещё не выписан в системе, но уже проведён в 1С
- Ошибка в номере ЭСФ при вводе в 1С
- ЭСФ был аннулирован в ИС, но не отражён в 1С

### Лист «Только в ИС ЭСФ» 🟠

Счета-фактуры, которые есть в ИС «ЭСФ», но **не отражены** в 1С.

Возможные причины:
- Не проведён документ в 1С
- Получен ЭСФ от контрагента, который не был обработан бухгалтером

### Лист «Дубликаты» 🟡

Номера ЭСФ, которые встречаются **несколько раз** в одном из файлов.

Требует проверки: возможно двойной ввод документа или ошибка нумерации.

### Лист «Расхождения по реквизитам» 🔵

Счета-фактуры, которые найдены в обоих файлах, но у них **не совпадают реквизиты** (сумма, дата, ИНН и т.д.).

Для каждого расхождения — отдельная строка. Столбцы «Значение в 1С» и «Значение в ИС ЭСФ» выделены **жирным** для удобного сравнения.

### Лист «Полностью совпадают» 🟢

Счета-фактуры, по которым **всё совпало**. Эти строки не требуют внимания.

## 5. Частые вопросы

### ❓ Что делать, если колонки называются иначе?

Откройте `config.yaml` и исправьте названия. Например, если в вашем файле 1С колонка называется не «Номер ЭСФ», а «№ ЭСФ»:

```yaml
key_column:
  in_1c:  "№ ЭСФ"   # ← исправлено
  in_esf: "Рег. номер"
```

Аналогично для любых других полей в разделе `fields`.

> **Важно:** Название должно совпадать с заголовком колонки в Excel **слово в слово**, включая пробелы. Регистр учитывается.

### ❓ Скрипт пишет «Файл не найден»

Убедитесь, что:
1. Файл лежит в папке `input/`
2. Имя файла в `config.yaml` совпадает с реальным именем файла (включая расширение `.xlsx` или `.csv`)
3. Нет лишних пробелов в имени файла

### ❓ Что делать, если кодировка CSV неверная (кракозябры)?

Измените параметр `csv_encoding` в `config.yaml`. Попробуйте варианты:
```yaml
csv_encoding: "cp1251"      # Стандартная Windows-кодировка для русского языка
csv_encoding: "utf-8"       # UTF-8 без BOM
csv_encoding: "utf-8-sig"   # UTF-8 с BOM (по умолчанию)
```

### ❓ Разделитель в CSV — запятая, а не точка с запятой

```yaml
csv_delimiter: ","
```

### ❓ Скрипт не запускается — ошибка «python не является внутренней командой»

Установите Python с [python.org](https://www.python.org/downloads/). При установке обязательно поставьте галочку **«Add Python to PATH»**.

### ❓ Суммы совпадают, но скрипт показывает расхождение

Увеличьте параметр `amount_tolerance`. Например:
```yaml
amount_tolerance: 2.0   # Допуск 2 тенге
```

### ❓ Как собрать .exe для запуска без Python?

Установите PyInstaller и запустите `build.bat`:
```bash
pip install pyinstaller
build.bat
```

Файл `ЭСФ_Сверка.exe` появится в папке `dist/`.
